## 2. Vì sao Kỹ thuật đảo ngược (Reverse Engineering) là lựa chọn tối ưu?

1. **Chuẩn giáo trình Bảo trì phần mềm**: Reverse Engineering là trụ cột cốt lõi trong chu trình bảo trì (Program Comprehension $\rightarrow$ Reverse Engineering $\rightarrow$ Restructuring / Refactoring $\rightarrow$ Forward Engineering).
2. **Khớp 100% định hướng Backend Java Spring Boot**: Khi tiếp nhận một hệ thống cũ (legacy system) không còn tài liệu thiết kế hoặc người cũ đã bàn giao, việc đảo ngược mã nguồn Java ra Class Diagram, ERD, Dependency Graph là kỹ năng thực chiến sống còn của kỹ sư Backend.
3. **Điểm nhấn sáng tạo (AI Integration)**: Kết hợp sơ đồ trích xuất từ Visual Paradigm với LLM / AI để tự động đánh giá tác động thay đổi (Change Impact Analysis) và đề xuất kế hoạch tái cấu trúc, tạo sự khác biệt vượt trội so với các nhóm chỉ đọc tài liệu lý thuyết.
